它能做什么 · 7 项

刷怪不站桩

到了刷怪区,worker 在你框出来的区域里一直走动。它自己不按攻击键,输出靠 florr 自带的「反转攻击键」,让花瓣一直张开。每轮进游戏后,worker 会把这个设置写成你在时块里配的值。

  • 刷怪区用两个角框出来:左上 + 右下
  • 写设置失败只在日志里提示;这时去 设置 → 控制 手动勾上
  • 可选:进游戏 / 到刷怪区各按一次换装键(按住 k 或 l 再按数字),默认关

识怪

直接解码游戏画面的绘制调用(圆形填充、血条、文字),读出每只怪的位置、血量和稀有度。不跑图像模型,也不需要任何模型文件。

  • Mythic 及以上:专门追击、走位
  • Ultra 里蝎子、甲虫这类打不过的:主动躲开
  • 普通怪不专门追,靠反转攻击键顺路打
  • 目前只对沙漠图有意义;稀有度按中文客户端实测
每次死亡
死亡→ 点继续→ 点开始→ 重新寻路→ 回到刷怪
连续没刷满时长的轮数(阈值 3)
1 2 3 → 换服 cp6.forceServerID(…)

死亡与换服

死了自动点继续、点开始,再从出生点寻路回刷怪区。连续几轮都没撑够设定的刷怪时长,就试着换一台服务器:从 florr 公开的服务器列表里挑一台同生态区的,调用页面自己的函数重连。

  • 刷怪时长和阈值在时块的「高级选项」里设
  • 换服可以按时块关掉
  • 换完会落在哪个生态区,目前没有确认过

多账号排班

按「星期 + 时段」排一张周表,每个时块单独选账号、地图、目标点、刷怪区、识不识怪、换不换服。点「开始调度」后,到了时块边界它会停掉 worker,切到那个账号的 Chrome,写好参数再重新开始。

  • 时段可以跨午夜;00:00–00:00 表示全天
  • 有重叠的时块,保存时直接拒绝
  • 每个账号一个独立的 Chrome profile,登录一次就行

自动寻路

每一帧截小地图,找你自己那个黄色标记定位,在仓库自带的地图上规划路线,自己走到你点的目标点。路线贴着墙角走,不会卡在墙上蹭。

  • 目标点和刷怪区在控制面板的地图选择器里点出来
  • 走出刷怪区,会自己走回区内最近的位置
  • 蚁穴要先进花园,再踩洞口传送过去

它对游戏页面做了什么

请知悉

本程序不往游戏进程里注入 DLL,也不读取、不改写你和游戏服务器之间收发的消息内容。 它靠 Chrome 的调试接口(CDP)对 florr.io 页面做下面这几件事:

读

给 Canvas 2D 的绘制函数装只读钩子,记录最近几帧的绘制调用,用来读出怪物、你自己和传送口的位置,以及怪物血量和稀有度。

读

给 WebSocket 构造函数套一层只读代理,只为读出当前服务器的短码,收发的消息本身不动。

写

每轮开局把「反转攻击键 / 反转防御键」这两个设置在页面 WASM 内存里的开关字节,写成你在时块里配置的值。

写

换服务器时调用游戏页面自己的 cp6.forceServerID(...),服务器编号取自 florr 公开的服务器列表接口,默认开启,可在时块里关掉。

另外:新建账号、登录、调度器切换账号时,程序会用 taskkill /IM chrome.exe /F 强制结束电脑上所有 Chrome 进程,再重新拉起——你别的 Chrome 窗口和没保存的标签页会丢,用前先保存好。拉起的 Chrome 带 --remote-debugging-port 参数,本机会开一个调试端口,别在这个 Chrome 里打开不信任的网站。

常见问题

可能会想先看看这些

杀毒软件报毒?

PyInstaller 打包的程序常被误报,可以加白名单,不放心就从 GitHub 下载源码运行。

双击没反应 / 闪退?

确认是把整个文件夹解压出来的,exe 旁边要有 _internal\ 文件夹。路径里有中文,或者放在网盘同步目录里,也可能出问题。

能把文件夹直接发给朋友吗?

先删掉 chrome-profiles\ —— 里面是你账号的登录态。

怎么更新?

打包版会自己提示新版本,点「立即更新」就行,你的配置和账号不会动。也可以重新下载解压到新文件夹,把旧文件夹里的 config.json 和 chrome-profiles\ 拷过去。

florr 更新之后会不会失效?

「反转攻击键 / 反转防御键」的内存地址是按某一个 florr 版本写死的,florr 大版本更新后可能失效。写失败只在日志里提示,不会卡住,这时去 设置 → 控制 手动勾上就行。

运行时电脑还能干别的吗?

不能。它会接管鼠标和键盘、截屏读小地图,游戏要全屏放在最前面,这台电脑同时干不了别的。

屏幕不是 1920×1080 能用吗?

坐标按 1920×1080 标定,启动时按屏幕分辨率自动缩放;非 16:9 的窗口可能有偏差。

有 Mac / Linux 版吗?

没有打包版。源码里有 macOS 和 Ubuntu(Xvfb 无头)的代码路径,但没有在真机上长期验证过。
